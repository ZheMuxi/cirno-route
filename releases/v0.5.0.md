# CirnoRoute v0.5.0

本版让用户指定哪些模型可以处理私密文件，并把官方 API 参考价与能力资料一起交给路由器。继续使用本地 Gemma 4 E4B、V2.1 评分标准和 0–4 分制。

| 功能 | 使用方式与行为 |
| --- | --- |
| 文件保护 | 用 `/bakaprivacy add ./private` 保护目录，再用 `/bakaprivacy local provider/model` 或 `/bakaprivacy trust provider/model` 登记许可模型。没有合适模型就停止；关闭自动路由也不会解除保护。 |
| 价格同步 | `/bakamodels refresh` 同时更新模型能力与价格。云模型按厂商官方 API 参考价比较，不以套餐价格代替；绑定本机推理的执行模型 API 费用为零。无法核实或已过期的价格保留未知。 |
| 价格与能力分开 | Gemma 接收独立的紧凑价格表，能力分仍衡量任务适配程度。选模时再应用 `/bakaprice` 选择的价格偏好。参考价不等于账单。 |
| 跨语言习惯匹配 | E5 找到接近但未达直接命中门槛的记录时，可由本地 Gemma 简短核验任务类型、难度和约束。通过后复用习惯模型，相同输入可命中进程内缓存。 |
| 自动路由 | 分别识别工具调用和严格 JSON 要求；判定任务缺材料时暂停回答。连续失败的执行端点暂时跳过。`/classify` 只分类，不执行。 |

安装模板从 Pi 读取可用候选，不预置云端模型目录或网关凭据。文件保护需要显式配置；回环代理不自动视为本地推理。详见[文件保护](../docs/file-privacy.md)、[模型价格](../docs/model-pricing.md)和[习惯路由](../docs/task-habits.md)。

**升级与回退：** 先退出 Pi 并保存本地未提交改动，再获取版本标签、切换源码并恢复锁定依赖：

```bash
git fetch origin --tags
git switch --detach v0.5.0
uv sync --frozen --python 3.12
./scripts/install-pi.sh
```

退回上一版时，将上述标签换成 `v0.4.0`。**v0.4.0 不执行文件保护规则**；仍需限制文件外发的会话请留在本版。
