# 本地语义匹配与习惯路由

v0.4.0 新增本地使用习惯，不改变 Gemma 4 E4B、0–4 分制、默认 node-llama-cpp 后端或三档价格策略。功能变更见 [版本说明](../releases/v0.4.0.md)；源码回退目标为保留的 v0.3.0 标签。

## 使用

已有安装先从仓库根目录运行 `./scripts/install-semantic-runtime.sh`，然后重启 Pi。新安装的 `install-pi.sh` 已包含此步骤。首次需要向量时，插件自动下载并校验固定版本的 E5 模型。后续语义推理使用本机文件，匹配阶段不发送任务到互联网，不需要单独启动服务；正常回答仍交给用户配置的回答模型。

若出现 `SEMANTIC_DEPENDENCY_MISSING`，运行上述安装脚本补齐插件依赖；任务提交时不会自动执行 npm 安装。依赖故障不会阻止原 Gemma 路由。

```text
/bakahabits prepare
/bakahabits status
/bakarouter
```

`prepare` 是可选的提前下载/加载。习惯学习配置默认开启，但自动选模仍需 `/bakarouter`。现有习惯不会自动从历史聊天导入，初始计数为零。

| 命令 | 行为 |
| --- | --- |
| `/bakahabits status`（或无参数） | 查看开关、门槛、分组数和成功使用总数 |
| `/bakahabits on` | 开启学习与习惯匹配 |
| `/bakahabits off` | 停止学习与匹配，释放语义进程；自动路由恢复每次 Gemma 分类 |
| `/bakahabits threshold 5` | 设置累计门槛，范围 1–1000，默认 5 |
| `/bakahabits prepare` | 提前准备 E5 权重与本地运行时 |
| `/bakahabits clear` | 清空习惯记录；也可重建损坏或不兼容的记录文件 |
| `/classify 任务` | 始终调用分类流程，不命中习惯、不执行、不学习 |

开关和门槛保存在本机习惯文件，优先于初始配置。更改 `config/pi-classifier.json` 的默认值不会覆盖已保存的用户设置。`/bakarouter off` 只关闭自动选模；习惯学习开启时，用户手动选择的模型仍可通过成功回答积累计数。若要全部关闭，使用 `/bakahabits off`。

## 计数与同类型判定

1. 手动通过 `/model` 或模型快捷键选择：只有这条路径使用轻量规则，识别明确操作；缺材料、含糊或复合请求不记录。自动路由开启时，这次手动选择优先用于下一轮，之后恢复自动路由。路由关闭时，后续沿用该手动选择。
2. 普通 Gemma 路由：在原评分的同一次生成中附带 `task_profile`，包含操作类型、难度、必要能力与是否可复用。**不使用轻量规则预分类或改写 Gemma 的类型。** 第一批请求生成标签，其余批次仅评分。标签校验失败只放弃学习，不丢弃有效评分。
3. 在 Pi 完成回答后，核对实际 provider/model、正常结束标记与非空回答，才增加一次计数。报错、中止、截断、失败工具、换模、追加多个用户请求的回合不计入。同一回合的多个工具续传不重复计数。
4. 同一分组内某个模型达到 5 次、且使用次数严格高于其他模型后，才可成为习惯模型。并列第一不直接选模。
5. 新任务先由 E5 匹配已有任务样本。只有足够相似、与其他类型有足够差距且胜出模型仍可用时，直接交给 Pi 执行，跳过 Gemma。命中会提示类型和模型，回答仍显示实际模型；**命中后的执行不增加计数，也不增加语义样本。**

分组键包括操作、难度、必要能力，以及价格偏好、价格表和模型目录/端点的指纹。希望便宜、均衡、接受昂贵分别累计；改价、价格过期或目录变化会使旧范围暂不命中，旧记录仍保留。手动记录反映用户在该价格档位下的实际选择，可能与价格算法建议不同。研究资料更新不自动重算习惯；需要重新学习时使用 `clear`。

Pi 1.2.0 无法区分用户 `/model` 和其他扩展发起的非本插件 `setModel()`；两者均可被视为显式换模。启动恢复的模型和本插件自己的选模不会被当作手动选择。安装多个自动换模扩展时需注意这一限制。

## 语义模型与匹配边界

使用 [multilingual-e5-small](https://huggingface.co/intfloat/multilingual-e5-small) 的 [Xenova ONNX INT8 转换](https://huggingface.co/Xenova/multilingual-e5-small)，384 维。语义匹配不是生成式 LLM。默认使用紧凑分词器和 `onnxruntime-node`，保留原生 `tokenizers` 兼容入口；依赖安装在插件私有目录，通过私有管道调用，不监听端口。依赖由 `package-lock.json` 锁定；权重 revision、大小及 SHA-256 固定在 [清单](../packages/pi-extension/semantic-runtime/model.json)。

- 五个必需文件合计约 **135.4 MB**，其中 ONNX 权重约 118.3 MB；不等于实际内存。
- 输入两侧均加 `query: ` 前缀，平均池化并 L2 归一化。最多 512 token，**不截断**；超过上限回到 Gemma，并跳过该任务的习惯学习。
- 默认相似度至少 **0.985**，与第二接近分组的差距至少 **0.04**。未达到计数门槛的其他分组也参与歧义检查。
- 每组最多保留最近 8 个不同任务的向量样本，不以习惯命中扩充样本；最多 128 个分组，满额后提示并停止新增分组。
- 支持多语言输入，但严格门槛会放弃部分跨语言等义匹配。不同主题的同类任务也可能不命中，继续让 Gemma 识别并学习。当前目标偏向减少误命中，而非最大化命中率。
- E5 相似度不能证明任务约束等价。新增工具、严格格式或难度要求仍有误匹配风险，Gemma 的类型标签也会出错。成功回答只表示正常完成，不代表用户认可或答案正确；本版没有满意度、反馈纠错、衰减或偏好画像。

## 本地存储与生命周期

记录默认位于 `.runtime/task-habits.json`，保存模型计数、类型、任务哈希及向量，**不保存任务原文或 API 密钥**。向量仍是个人任务衍生数据，应留在本机。文件权限 0600，使用临时文件原子替换和进程锁，重复回合 ID 不会重复计数。损坏/不兼容文件停用学习与匹配并提示，不静默覆盖；可显式 `clear`。

权重默认位于 `.runtime/semantic/e5-small-q8`。E5 按需加载，空闲 15 秒释放进程，退出或重载 Pi 时立即清理。下载时仅访问固定公开权重地址；任务正文只在本地子进程管道中传递。`.runtime`、`node_modules`、权重、会话和密钥均不进入版本管理。

## 内存优化

默认[紧凑分词器](../packages/pi-extension/semantic-runtime/compact-tokenizer.mjs)保留全部 250,002 个词条、原有分数和特殊 token，以有序词表的前缀检索代替大型对象树。分词与路径评分复用固定版本的 `@huggingface/tokenizers`；Unicode 归一化读取原模型的完整 charsmap，并兼容原生 HF 的字素边界规则，不能用普通 NFKC 替代。没有缩减语言、改变量化精度或缩短输入上限。

E5 子进程加载分词器后执行一次垃圾回收，避免解析临时对象与 ONNX 加载叠加。macOS 下仅对这个子进程启用 `MallocSpaceEfficient=1`，尊重用户显式设置；不会修改 Pi 或 Gemma 的分配器环境。ONNX 复用推理缓冲区，关闭按输入形状缓存的 memory pattern；空闲时仍释放整个进程。退出时等待原生线程清理，避免强制退出引起的 mutex 错误。

遇到分词兼容问题时，退出 Pi 后从仓库根目录运行：

```bash
CIRNO_SEMANTIC_TOKENIZER=native ./scripts/start-pi.sh
```

这只切回原生分词器，不改变 E5 权重、习惯记录指纹和匹配门槛。取消此环境变量即可恢复紧凑实现。现有记录可以继续使用，无需清空或重新学习。分词器依赖升级涉及模型内部接口，Node/ICU 升级也可能改变 Unicode 字素边界，因此运行时采用锁定依赖。

## 已知限制

语义相似度不能保证任务约束等价，类型和难度识别也可能出错。严格门槛会漏掉部分跨语言等义请求；未命中时继续使用 Gemma，不保证所有同类任务都会形成或命中习惯。

新增任务标签会改变 Gemma 的完整输入，个别能力分可能变化；基础 V2.1 评分文件未修改。标签有独立提示词哈希；只在需要学习时请求。关闭习惯或使用 `/classify` 不附加类型提示词。

缺少必要材料时，Gemma 仍可能给出评分，或将任务错误标为可复用；标签有效不代表材料完整性已被可靠确认。结构无效或不适合复用的标签会跳过学习，但不能保证所有语义错误都会被识别。正常完成的回答即使内容有误，也可能增加习惯次数；当前没有满意度判断、反馈纠错、时间衰减或模型微调。

## 回退

最快方式是在 Pi 输入 `/bakahabits off`。也可退出 Pi 后，从仓库根目录运行：

```bash
CIRNO_HABITS=0 ./scripts/start-pi.sh
```

这会完全禁用习惯服务，保留原 Gemma/价格路由和已有记录。完整源码回退基线是固定标签 `v0.3.0`；按 [v0.4.0 回退步骤](../releases/v0.4.0.md#关闭功能与回退)先退出 Pi、保留未提交改动，再切换版本并恢复对应依赖。勿用 `reset --hard` 或 `clean` 丢弃工作，也不覆盖旧标签。v0.3.0 不读取习惯文件，回退无需迁移或删除记录。
