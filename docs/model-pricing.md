# 模型价格与价格偏好

Pi 分类结果新增价格资料与推荐模型，继续使用 Gemma 4 E4B、V2 和紧凑传输。Gemma 只评估任务能力；本地程序随后结合价格选择推荐，不向 Gemma 添加价格上下文，不增加推理次数。

价格策略用于推荐，也用于开启 `/bakarouter` 后的普通输入自动选模；`/classify` 仍只显示评分和推荐，不执行或切换模型。普通输入隐藏各模型评分，每次回答显示实际执行模型。开关及失败处理见 [自动路由](automatic-routing.md)。没有用户习惯学习或消费预算。

## 使用

重启 Pi 或执行 `/reload`，然后输入 `/bakaprice` 打开三选一菜单；也可以直接输入：

| 命令 | 行为 |
| --- | --- |
| `/bakaprice 希望便宜` | 能力达标时尽量选低价 |
| `/bakaprice 均衡` | 能力差距较小且节省明显时选便宜模型，默认档位 |
| `/bakaprice 接受昂贵` | 优先任务质量，评分相同时选已知价格更高的模型 |
| `/bakaprice status` | 查看当前设置 |
| `/classify 你的任务` | 查看能力分、各模型价格、当前偏好和推荐依据 |

英文参数分别为 `cheap`、`balanced`、`premium`。RPC/非交互模式下无参数只显示当前设置，不等待菜单操作。设置保存在 `.runtime/router-preferences.json`，重启或 `/reload` 后保留；该文件不进入 Git。只保存用户明确选择的一项设置，不提取习惯。

## 选择规则

策略版本为 `quality-price-v1`。能力分仍是 0–4 的适配等级，不是成功概率，价格不会改变分数。各档位都要求有效 Gemma 分类、有证据、能力至少 3/4。阻断、规则回退、明确缺少任务资料或所有候选均未达标时不推荐。目录里部分未知候选弃权，不妨碍其他有依据的候选参与。

- **希望便宜**：在达标且价格有效的候选中取参考成本最低者；同价取能力更高者。没有可比价格时退回能力优先，不将未知价格当免费。
- **均衡**：先取能力最高者，同分取便宜者。仅当便宜候选能力差距不超过 1 级、且成本不到能力最高候选的三分之一时，改选便宜候选。最高能力候选价格未知时不推算节省比例。
- **接受昂贵**：先取能力最高者，同分取已知价格更高者。未知/过期价格不算昂贵；能力更低的模型不会仅因贵而越过能力更高的模型。此同分规则是用户明确选择，不代表价格证明质量。

能力和价格均相同时用稳定 candidate ID 决定显示顺序，避免输入候选换序改变程序选择。推荐模型置顶；其余按能力、对应档位的同分价格规则排列。所有候选保留，包括无价格、能力未知和未达门槛的候选。

例：A 为 4 分、标准比较成本 $0.010；B 为 3 分、$0.002。希望便宜和均衡推荐 B；接受昂贵推荐 A。若 A、B 都为 4 分，前两档推荐 B，接受昂贵推荐 A。

## 价格口径

统一使用 **USD / 一百万 token**，分开记录输入、输出及可选缓存读取单价。比较采用同一工作量：1,000 输入 token + 1,000 输出 token、无缓存命中：

```text
比较成本 = (输入单价 + 输出单价) / 1000
```

这是排序参考，不是本次对话账单。当前不预测回答长度，不计算历史/工具上下文、思考 token、各家 tokenizer 差异、搜索费用、时段/批量折扣、税费和网关套餐。长输入或长输出任务的实际成本排序可能不同。DeepSeek 使用高峰标准价；缓存单价仅记录，暂不参与排序。

价格位于 `config/model-prices.json`，每次分类重新读取，无需重查能力缓存。每条价格包含 `source`、来源 URL、UTC 核对日 `checked_at`、UTC 有效期 `valid_until` 和备注：

- `official`：直接调用供应商的公开标准价。
- `reference`：网关模型采用的官方参考价，不代表该网关真实收费或已验证后端身份。
- `user`：用户根据实际渠道填写的价格。
- `local`：用户明确配置的本地 API 成本，不代表电费、内存或硬件成本。

按完整 `provider/model` 精确匹配，不把基础型号价格套到 thinking/high/low 等后缀，也不从 Pi 未配置价格时显示的零推断免费。缺失、明确为 null、过期或未来日期均不参与价格比较；显式配置的有效零价才按零计算。仅接受 USD，避免静默混用人民币和美元。

## 验证

离线测试覆盖三档取舍、昂贵档同分选择高价、能力门槛、未知/过期/零价、候选换序、币种与数值校验、偏好持久化、菜单取消、普通评分隐藏及错误脱敏。价格变更不修改能力卡片或 Gemma 请求。

```bash
node --test packages/pi-extension/*.test.mjs
# 真正调用本地 Gemma；复用能力缓存，缺少有效缓存时可能触发既有联网研究：
.venv/bin/python scripts/pi-pricing-smoke.py
```

实测脚本依次切换三档，分类同一合成编程任务，核对完整候选、价格和推荐结果、能力卡片/提示词哈希不变且没有执行模型调用；退出时恢复原价格偏好。报告保存在 Git 忽略的 `.runtime/pi-pricing-*.report.json`。
